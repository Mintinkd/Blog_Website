外链 · iframe

与博客视觉对齐的设计要点

  • 主色沿用安知鱼蓝 #49b1f5，卡片使用半透明磨砂衬底 + 1px 边框 + 16px 圆角，与全局 .main-content 一致
  • 深浅双主题自动跟随站点主题；播放按钮/进度条均用主色，hover 有轻微上浮反馈
  • 语音卡：识别音频后缀 → 图标 + 标题 + 播放按钮，播放时展开进度条与时长
  • 视频卡：16:9 封面 + 中央播放键 + 时长角标，点击后嵌入播放器（平台外链走 iframe）
  • 移动端：单列全宽，按钮不小于 44px 触控目标
