# 响应式设计

本文档记录全站响应式布局的断点、布局策略、移动导航与验证矩阵。
实现以 `src/styles/responsive.css` 为全局响应式层，页面级差异写在各自的
Astro scoped style 中；两者冲突时页面级样式优先。

## 设计目标

- 从 280px 小屏手机到 3440px 超宽屏都不出现页面级横向滚动、内容溢出或元素重叠。
- 竖屏、横屏、超宽屏分别验证；不假设用户只使用 375px 手机。
- 保留既有视觉风格（毛玻璃衬底、卡片、圆角、分类渐变），只调整尺寸与排布。
- 触控目标不小于 44px；刘海屏 / 手势条通过 `env(safe-area-inset-*)` 避让。
- 不覆盖后台「可视化配置中心」写入的 `--content-max-width`、`--header-height`
  等用户设置（这些变量带 `!important`，由 `src/utils/settings.ts` 注入）。

## 断点

移动优先，`responsive.css` 与页面样式统一使用以下区间：

| 区间          | 名称      | 主要变化                                            |
| ------------- | --------- | --------------------------------------------------- |
| `< 480px`     | compact   | 单列；页头图标 34px；站点名超长时省略；页脚纵向堆叠 |
| `480–767px`   | mobile    | 单列；保留移动导航；正文 16px 起                    |
| `768–1023px`  | tablet    | 导航恢复横排；首页两列；文章列表改横向卡片          |
| `1024–1279px` | laptop    | 版心达到上限（默认 1200px）；文章列表横向卡片       |
| `1280–1679px` | desktop   | 首页三列；正文与列表保持阅读宽度                    |
| `1680–1919px` | wide      | 版心居中，不继续拉伸正文                            |
| `≥ 1920px`    | ultrawide | 页边距固定 32px；卡片仍按三列排布，避免巨卡         |

另有一条独立的高度断点，用于手机横放和小窗口：

```css
@media (orientation: landscape) and (max-height: 500px) { ... }
```

该查询压缩首屏留白、文章头图（≤120px）和悬浮一言的底部偏移，保证 375px 高的
视口里仍能看到正文开头。

## 页面骨架

- 版心宽度由 `--content-max-width` 控制（默认 1200px）。响应式层只改页边距，
  不覆盖版心宽度；超宽屏把 `--page-gutter` 固定为 32px，避免 `4vw` 无限增大。
- 页面左右留白：`--page-gutter: clamp(0.75rem, 4vw, 2rem)`（12px → 32px），
  并叠加 `safe-area-inset-left/right`。
- 页头下方留白：`--page-top-gap: clamp(1.5rem, 5vw, 3rem)`；实际
  `padding-top` 为页头高度 + 安全区 + 该留白。
- `.main-content` 是页面级毛玻璃衬底：
  - `≥ 768px`：`padding: 1.5rem 2rem`，衬底 74% 主题背景色 + blur；
  - `< 768px`：`padding: 1rem clamp(0.5rem, 2vw, 0.75rem)`，衬底提高到 86%，
    既保留页面标题/摘要与背景图之间的对比度，又不让三层 padding 把正文挤成细柱。
- 所有 flex / grid 子项默认 `min-width: 0`；元信息、标签、页脚允许换行。
- 长标题、长英文单词、长链接使用 `overflow-wrap: anywhere`；正文链接也允许断行。

## 排版与组件

### 首页

- Hero 标题 `clamp(1.9rem, 6vw, 3rem)`，副标题 / 描述、上下留白同样按视口流式缩放。
- 按钮组可换行；按钮最小高度 44px。
- 文章网格：`< 768px` 单列，`768–1279px` 两列，`≥ 1280px` 三列；
  卡片内部 padding、标题、标签与页脚均为流式尺寸。
- 卡片封面保持固定比例，文字区域 `min-width: 0`，不因长标题撑破网格。

### 文章列表

- `< 768px`：纵向卡片，封面在上（21:9）。
- `≥ 768px`：横向卡片，封面在左、正文在右；封面列 `minmax(220px, 30%)`，
  最小高度 170px。这样 1000px+ 的单列列表不会出现 450px 高的巨型封面。
- 摘要默认两行截断，横向卡片放宽到三行；分页按钮可换行并保持 44px 触控高度。

### 文章详情与正文

- 详情卡片最大宽度 `min(760px, 100%)`，卡片 padding
  `clamp(1rem, 3vw, 2rem)`。
- 标题 `clamp(1.4rem, 4.5vw, 2rem)`；头图 `max-height: clamp(200px, 40vw, 360px)`；
  无封面时的分类渐变区 `min-height: clamp(140px, 28vw, 200px)`。
- 矮横屏下头图最高 120px，标题降到 1.3–1.6rem，让正文进入首屏。
- 正文 `font-size: clamp(1rem, 0.35vw + 0.92rem, 1.05rem)`，手机不低于 16px，
  避免 iOS 聚焦缩放；标题逐级 `clamp()`。
- 代码块在自身容器内横向滚动；手机上的宽表格改为 `display: block; overflow-x: auto`，
  由表格内部滚动，不撑破页面。
- 所有带 `id` 的正文锚点使用 `scroll-margin-top` 避让固定页头（含安全区）。

### 其他页面

- 分类 / 标签详情页的页头在 `< 768px` 改为纵向堆叠，避免标题与「所有文章」互挤。
- 归档时间线、分类 / 标签云、搜索、隐私、关于、404 均使用流式 page title
  （`--page-title-size: clamp(1.4rem, 4vw, 1.75rem)`）和可换行元信息。
- 搜索框、评论输入框、点赞按钮、友链列表在窄屏下 `min-width: 0`，
  输入控件不超出容器；触控设备上的按钮 / 标签 / 链接最小高度 44px。
- 后台 `/admin` 同样继承移动导航和页面留白；侧栏可纵向滚动，面板标题可换行，
  表格在自身容器内横向滚动。

## 移动导航

- `< 768px` 显示汉堡按钮（`#nav-toggle`），隐藏横排 `.nav-links`。
- 菜单复用同一份 `.nav-links` 链接，不复制 DOM；展开后是固定定位的下拉面板，
  最大高度 `100dvh - 页头高度`，内部可滚动。
- 交互：
  - `aria-expanded` / `aria-controls="site-nav"` 同步；
  - 打开后焦点移到第一个链接；
  - `Escape` 关闭并把焦点还给汉堡按钮；
  - 点击菜单外区域关闭；
  - 视口切到 `≥ 768px` 自动关闭；
  - `astro:after-swap` / `astro:page-load` 后复位，兼容 ClientRouter。
- 每个菜单项最小高度 44px；面板背景不透明度 0.97，避免背景文字透出干扰阅读。
- 菜单文案使用 i18n 键 `nav.menu`（中 / 英各一份）。

## 触控、安全区与浮动组件

- `@media (pointer: coarse)` 下，主要按钮、标签、分类项、友链、分页按钮
  最小高度 44px；页头图标最小 40px。
- 页头高度与顶部 padding 叠加 `env(safe-area-inset-top)`；页脚、页面左右留白
  叠加对应的安全区变量。
- 悬浮一言：
  - `≥ 768px` 保持可拖动，位置由脚本按百分比记忆；
  - `< 768px` 由 CSS 固定在右下角（`bottom: 5.5rem`，避让回到顶部按钮），
    禁用拖动，卡片宽度限制为 `min(272px, 100vw - 1.5rem)`；
  - 矮横屏把底部偏移降到 4rem。
- 回到顶部按钮在 `< 768px` 固定为 44×44px，位于右下角安全区。

## 有意保留的溢出 / 截断

以下情况会被自动审计脚本报告为「溢出」，但属于设计意图，不应修复：

- 文章列表页 / 详情页的封面贴边（详情头图用负 margin 出血到卡片边缘）。
- `.prose pre`、手机上的 `.prose table`、后台数据表格：容器内部横向滚动。
- 站点名 `#site-logo-text`：窄屏下 `text-overflow: ellipsis`。
- `.sr-only` 屏幕阅读器文本：1px 绝对定位。
- 全站固定背景层 `.site-bg`、悬浮一言、装饰性滚动进度条。

审计时已排除这些节点；除此之外，12 个视口 × 13 条路由均无横向滚动、
无内容溢出、无意外裁切。

## 验证矩阵

### 视口

| 设备类型 | 视口                 |
| -------- | -------------------- |
| 极窄手机 | 280×653              |
| 小屏手机 | 320×568              |
| 主流手机 | 375×667、390×844     |
| 手机横屏 | 667×375              |
| 平板     | 768×1024、1024×768   |
| 笔记本   | 1280×800             |
| 桌面     | 1440×900             |
| 宽屏     | 1920×1080            |
| 超宽屏   | 2560×1080、3440×1440 |

### 路由

`/`、`/articles`、`/articles/ssr-regression`、`/archives`、`/about`、`/search`、
`/privacy`、`/categories`、`/tags`、`/categories/tech`、`/tags/css`、`/404`、`/admin`。

### 自动检查项

- 页面级横向滚动：`documentElement.scrollWidth <= clientWidth + 1`。
- 元素越界：排除上述有意节点后，所有元素 `left >= -1` 且 `right <= viewport + 1`。
- 裁切：`scrollWidth > clientWidth` 且自身不是横向滚动容器时报警（排除 `pre` /
  `sr-only` / 省略号 / 文章头图出血）。
- 移动导航：展开后 `aria-expanded=true`、面板在视口内、链接 ≥44px、
  首个链接获得焦点、`Escape` 关闭并还焦、点击外部关闭、页面不产生横向滚动。
- 深色主题：375px 与 1440px 下抽检首页、文章列表、文章详情、后台。

### 最近一次结果（2026-11-12）

- 12 个视口 × 13 条路由 = 156 个组合，加 8 个深色主题抽检，共 164 个组合。
- 通过：164 / 164；页面级横向滚动 0，意外溢出 0，意外裁切 0。
- 移动导航在 280 / 375 / 667×375 下全部通过。
- 视觉检查覆盖首页、文章列表、文章详情、归档、关于、搜索、隐私、分类、标签、
  404、后台登录页；深色主题与 280px 极窄屏重点检查。

## 维护约定

1. 新的响应式规则优先写进 `src/styles/responsive.css`；页面独有布局写在页面
   scoped style 中，并沿用本文断点。
2. `responsive.css` 必须在 `BaseLayout.astro` 中于 `global.css` **之后**单独 import。
   放回 `global.css` 顶部的 `@import` 会被后续全局规则覆盖。
3. 页面 scoped style 的优先级高于 `responsive.css`；需要统一覆盖时使用
   `--page-title-size` 等变量，而不是堆叠 `!important`。
4. 新增页面或卡片组件时，按「280px 单列 → 768px 两列 / 横向 → 1280px 三列」
   检查，并确认长标题、长英文、宽表格、空状态、加载失败状态都不溢出。
5. 不覆盖 `--content-max-width` / `--header-height`；它们属于用户配置。
