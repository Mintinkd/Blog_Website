## 实现摘要

1. **单点解析** `worker/src/utils/client_ip.ts`：`resolveClientIp(request, secret)` 统一「验签 X-Real-IP → CF-Connecting-IP → XFF[0] → unknown」四级优先级，返回 `{ip, source}`；`getClientIpString` 便捷包装。
2. **可信跳验签**：Pages 两转发点（`src/pages/api/v1/[...path].ts`、`src/utils/articleServer.ts`）用共享 secret `VISITOR_IP_SIGNING_SECRET` 对 cf-connecting-ip 做 `HMAC-SHA256("client-ip:v1:"+ip)` 写入 `X-Real-IP-Sig`；代理层同时 `delete` 客户端自带的 `X-Real-IP` / `X-Real-IP-Sig` 防透传。Worker 验签通过才采信 X-Real-IP，常数时间比较。secret 未配置 fail-closed 不采信 X-Real-IP。
3. **调用点全覆盖**：`like.ts`（2 处）、`comment.ts`、`rate_limit.ts`、`img_proxy.ts`、`text_proxy.ts` 共 5 处全部改用单点（票面写「四处」，实测扫描为 5 处，全改）。`img_proxy.clientIp` 保留导出名委托单点供 text_proxy 复用。
4. **三方一致守卫**：`tests/visitor-ip-signing.test.ts` 机械守卫前端 `signVisitorIp` 与 Worker `signClientIp` 逐字节一致 + 头名常量一致。
5. **配置文档**：README 新增「访客 IP 签名密钥」段，写明 Pages / Worker 双侧配置命令、fail-closed 后果、轮换语义。
