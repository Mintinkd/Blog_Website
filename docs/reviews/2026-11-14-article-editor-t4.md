## 3. #65 验收对照

- [x] **存量语料打开 / 保存后前台语义等价，lossy 默认进源码并可显式覆盖** —— 浏览器（系统 Edge + dev server）实测 15/15 `safe`、0/15 字节相同；集成测试覆盖 lossy → source → `overrideGuard()` → WYSIWYG。
- [x] **保存前守卫接入 `useArticleEditor`，WYSIWYG lossy 保存被阻止** —— `save()` 内对当前正文重新往返判定；测试钉住「0 个 PUT/POST、phase 保持 ready、lockHeld 保持 true、onError 提示、onSaved 未调用」，显式覆盖也不例外。
- [x] **打开未编辑不改正文；源码模式未修改保存原始字节** —— 集成测试断言 `form.content` / `baseline.content` 均为原始字节，源码模式 PUT body 的 content 逐字相等；`MilkdownEditor.vue` 的挂载与 `setMarkdown` 都不 emit change（代码级保证 + UI 实测默认无 lossy 提示）。**浏览器级「打开未编辑不产生正文变化」量化仍列为 T7 手工项**，不冒充实测。
- [x] **embed 锚点、表格、代码块、引用、图片保留** —— 15 条语料含 GFM 表格 / 围栏代码 / 引用 / 嵌套列表 / 图片 / 原始 HTML / `data-*` / 中文标点 / 硬换行 / 综合文档，全部语义等价；embed 单独验证逐字还原。
- [x] **包体在 T0 预算内** —— 182,117 B gzip < 358,400 B；`App.*.js` 中 `createEditor` 只有 1 处动态 `import()`、0 处静态 import，确认内核不进后台首屏。`classic.css`（1,088 B 变量）被 Astro 内联进首屏 HTML，**如实在 ADR 标注**：CSS 体积可忽略，但「CSS 完全不进首屏」严格来说未成立。
- [x] **预览与前台同一管线** —— 分屏右侧与 `EditorPreviewDialog` 都调用 `renderMarkdown`；parity 测试扩到 15 项，钉住 DOMPurify / sanitize-html 同白名单与守卫判定一致。
